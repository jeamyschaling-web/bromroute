# BromRoute v1.2 — testversie

Technische proef, niet gebruiken voor navigatie tijdens het rijden.

Wijzigingen: filtert de Overpass-opvraag op relevante wegtypen, probeert vier servers en geeft elke poging maximaal 35 seconden. Dit vermindert de opgevraagde data maar garandeert geen beschikbaarheid. Wegtoegankelijkheid en verkeersregels zijn niet gevalideerd.
