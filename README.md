# BromRoute v1.8 — technische test

Deze versie bouwt voort op v1.7.

- Vraagt eerst een kleiner gebied op bij openbare Overpass-servers om overbelasting te verminderen.
- Probeert meerdere servers; toont concrete foutmeldingen als ophalen niet lukt.
- Hergebruikt in dezelfde browsersessie eerder succesvol opgehaalde weggegevens.
- Behoudt adreszoekfunctie, experimentele routeberekening, alternatieven en tijdelijk vermijden van wegdelen.
- Laat bij een route zien of weggegevens uit een tijdelijke cache komen.

**Beperkingen:** Een kleiner opvraaggebied kan noodzakelijke omwegen missen. Openbare servers kunnen alsnog onbereikbaar zijn. De routes zijn niet juridisch gevalideerd voor brommobielen en mogen niet worden gebruikt als rijnavigatie.
